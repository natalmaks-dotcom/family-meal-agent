# 🍽️ Family Meal Agent

> An AI-powered bounded meal-planning agent that creates personalized weekly family dinner plans, learns from parental feedback, and continuously improves over time. The agent helps families with picky eaters by generating healthy weekly dinner suggestions while avoiding unnecessary repetition with kindergarten meals and learning from parents' feedback.

## Vision

The agent will:

- 📷 Read the weekly kindergarten menu from a photo
- 🌐 Search trusted German recipe websites
- 🧠 Consider family preferences and previous meals
- 🍽️ Generate five healthy dinner options
- 🛒 Create a consolidated shopping list
- 📧 Send a weekly email to both parents
- 📈 Learn continuously from email feedback
